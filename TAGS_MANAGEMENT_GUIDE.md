# Руководство по управлению тегами

## Обзор

Система управления тегами в Task Planner позволяет создавать, редактировать и удалять пользовательские теги для более эффективной организации задач.

## Доступ к управлению тегами

### Через главное меню
- Нажмите на иконку **тега** (📝) в верхней панели главной страницы
- Или используйте подсказку "Управление тегами"

## Основные функции

### 1. Создание нового тега

#### Шаги:
1. В разделе "Создать новый тег" введите название тега
2. Добавьте описание (необязательно)
3. Выберите цвет из предложенной палитры
4. Нажмите кнопку "Создать тег"

#### Особенности:
- **Уникальность**: Названия тегов должны быть уникальными
- **Автоматическое форматирование**: Названия приводятся к нижнему регистру
- **Цветовая палитра**: 12 предустановленных цветов на выбор
- **Описание**: Помогает понять назначение тега

### 2. Редактирование тега

#### Способы редактирования:
1. Нажмите иконку **редактирования** (✏️) рядом с тегом в списке
2. Форма автоматически заполнится данными тега
3. Внесите необходимые изменения
4. Нажмите "Сохранить"

#### Что можно изменить:
- Название тега
- Описание
- Цвет

### 3. Удаление тега

#### Процесс удаления:
1. Нажмите иконку **удаления** (🗑️) рядом с тегом
2. Подтвердите удаление в диалоговом окне
3. **Внимание**: При удалении тега он автоматически убирается из всех задач

#### Предупреждения:
- Система показывает количество задач, использующих тег
- Удаление необратимо
- Тег будет убран из всех связанных задач

## Статистика использования

### Информация о тегах:
- **Количество использований**: Показывает, в скольких задачах используется каждый тег
- **Автоматическое обновление**: Статистика обновляется при создании/изменении задач
- **Кнопка обновления**: Ручное обновление статистики в правом верхнем углу

## Технические детали

### Хранение данных
- **База данных**: Firestore
- **Коллекция**: `users/{userId}/tags`
- **Автоматическая синхронизация** между устройствами

### Поля тега
```
{
  "name": "work",           // Название (нижний регистр)
  "color": "#2196F3",       // Цвет в HEX формате
  "description": "...",     // Описание тега
  "createdAt": timestamp,   // Дата создания
  "updatedAt": timestamp    // Дата последнего изменения
}
```

### Валидация
- **Название**: Обязательное поле, не может быть пустым
- **Уникальность**: Проверка при создании нового тега
- **Цвет**: Один из предустановленных цветов

## Интеграция с задачами

### Связь с системой задач:
1. **Создание тегов** автоматически обновляет список доступных тегов в задачах
2. **Удаление тегов** убирает их из всех связанных задач
3. **Статистика** показывает реальное использование в задачах

### Обновление интерфейса:
- После создания/удаления тега список в задачах обновляется автоматически
- Фильтры по тегам на главной странице также обновляются

## Лучшие практики

### Именование тегов:
- Используйте короткие, понятные названия
- Избегайте дублирования смыслов
- Создавайте тематические группы

### Организация:
- **Контекст**: work, personal, study
- **Приоритет**: urgent, important, later
- **Проект**: project-a, project-b
- **Тип**: meeting, call, email

### Цветовое кодирование:
- **Красный**: Срочные/важные задачи
- **Зеленый**: Завершенные проекты/позитивные задачи
- **Синий**: Рабочие задачи
- **Оранжевый**: Личные дела
- **Фиолетовый**: Творческие/проектные задачи

## Советы по использованию

1. **Начните с базовых тегов**: work, personal, urgent
2. **Добавляйте по необходимости**: Не создавайте слишком много тегов сразу
3. **Регулярно просматривайте статистику**: Удаляйте неиспользуемые теги
4. **Используйте описания**: Для сложных или специфических тегов
5. **Планируйте цвета**: Создайте систему цветового кодирования

## Устранение неполадок

### Тег не появляется в списке задач:
- Проверьте интернет-соединение
- Перезапустите приложение
- Убедитесь, что тег сохранен

### Не удается удалить тег:
- Проверьте права доступа
- Убедитесь в стабильном соединении с интернетом

### Статистика не обновляется:
- Нажмите кнопку обновления (🔄) в правом верхнем углу
- Проверьте синхронизацию с Firestore
