# 🕐 Функциональность времени для задач

## Обзор
Добавлена возможность указывать время выполнения задач (опционально). Время отображается в правом углу карточки задачи, если оно установлено.

## ✨ Новые возможности

### 1. Добавление времени к задаче
- При создании или редактировании задачи появилось новое поле "Due Time (Optional)"
- Нажмите на поле, чтобы открыть стандартный выбор времени Flutter
- Время можно очистить, нажав на кнопку "Clear time" (X)

### 2. Отображение времени
- Время отображается в виде красивого чипа в правом углу карточки задачи
- Чип содержит иконку часов и отформатированное время
- Если у задачи есть и время, и изображения, они отображаются вертикально

### 3. Сохранение в базе данных
- Время сохраняется в Firestore в формате "HH:MM" (например, "14:30")
- Поле опциональное - если время не установлено, сохраняется null

## 🔧 Технические детали

### Обновленные файлы:
1. **`lib/models/task.dart`** - добавлено поле `dueTime`
2. **`lib/services/firestore_service.dart`** - обновлены методы сохранения
3. **`lib/screens/task_detail_screen.dart`** - добавлен UI для выбора времени
4. **`lib/screens/home_screen.dart`** - обновлено отображение в списке
5. **`lib/utils/time_formatter.dart`** - новая утилита для работы со временем

### Новая утилита TimeFormatter:
```dart
// Форматирование времени для отображения
TimeFormatter.formatTime(time, context)

// Конвертация в строку для БД
TimeFormatter.timeToString(time)

// Парсинг из строки БД
TimeFormatter.stringToTime(timeString)

// Создание красивого чипа времени
TimeFormatter.buildTimeChip(time, context)
```

## 📱 Использование

### Создание задачи с временем:
1. Нажмите "+" для создания новой задачи
2. Заполните название и описание
3. Выберите дату
4. **Нажмите на "Due Time (Optional)"** для выбора времени
5. Сохраните задачу

### Редактирование времени:
1. Нажмите на существующую задачу
2. Измените время или очистите его кнопкой "X"
3. Сохраните изменения

### Отображение в списке:
- Задачи с установленным временем показывают чип времени в правом углу
- Чип адаптируется к теме приложения (светлая/темная)
- Время отображается в локальном формате пользователя

## 🔄 Совместимость

### Обратная совместимость:
- Существующие задачи без времени продолжают работать
- Поле времени опциональное - не влияет на основную функциональность
- Все существующие функции сохранены

### Миграция данных:
- Автоматическая - новое поле `dueTime` добавляется как `null` для существующих задач
- При первом редактировании старой задачи поле времени становится доступным
