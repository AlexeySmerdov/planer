# 📝 Daily Tasks Feature Guide

## Overview

Система ежедневных задач позволяет создавать и редактировать текстовые заметки для планирования дня. Включает две отдельные страницы:
- **Задачи на сегодня** - планы и заметки на текущий день
- **Задачи на завтра** - планы и заметки на следующий день

## 🚀 Основные возможности

### ✅ Умное автосохранение
- **Сохранение при окончании ввода**: текст сохраняется автоматически при потере фокуса
- **Защитное сохранение**: дополнительное сохранение через 3 секунды бездействия
- **Сохранение при закрытии**: автоматическое сохранение при переходе на другую страницу
- **Без кнопок**: не требует нажатия кнопок "Сохранить"
- **Индикатор статуса**: показывает процесс сохранения в реальном времени

### ✅ Удобный интерфейс
- **Большое поле редактирования**: занимает всю доступную область экрана
- **Адаптивный дизайн**: поддержка светлой и темной тем
- **Интуитивные иконки**: легко узнаваемые символы для навигации
- **Подсказки в поле ввода**: информация о режиме автосохранения

### ✅ Синхронизация в облаке
- **Firestore интеграция**: данные сохраняются в облачной базе данных
- **Пользовательские документы**: каждый пользователь имеет собственные данные
- **Мгновенная загрузка**: быстрый доступ к сохраненным данным
- **Избежание дублирования**: сохранение только при реальных изменениях

## 🎯 Как использовать

### Доступ к страницам
В верхней панели приложения находятся две иконки:

1. **📅 Иконка "Сегодня"** (`Icons.today`) - открывает страницу задач на сегодня
2. **📅 Иконка "Завтра"** (`Icons.event`) - открывает страницу задач на завтра

### Редактирование текста
1. **Откройте нужную страницу** кликом по соответствующей иконке
2. **Начните печатать** в большом текстовом поле
3. **Завершите ввод** - кликните вне поля или перейдите на другую страницу
4. **Текст автоматически сохранится** при окончании ввода

### Автоматическое сохранение происходит:
- **🎯 При потере фокуса** - когда кликаете вне текстового поля
- **🚪 При закрытии страницы** - когда переходите на другой экран
- **⏰ Через 3 секунды бездействия** - как дополнительная защита

### Индикаторы статуса
- **🔄 В AppBar**: индикатор загрузки во время активного сохранения
- **💡 В поле ввода**: постоянная подсказка о принципе автосохранения

## 🔧 Техническая реализация

### Архитектура данных
```dart
// Структура пользовательского документа в Firestore
{
  "taskToday": "Текст задач на сегодня",
  "taskTomorrow": "Текст задач на завтра", 
  "updatedAt": Timestamp
}
```

### Ключевые компоненты

#### 1. UserService (`lib/services/user_service.dart`)
- **Назначение**: управление пользовательскими данными в Firestore
- **Методы**:
  - `updateTaskToday(String text)` - обновление задач на сегодня
  - `updateTaskTomorrow(String text)` - обновление задач на завтра
  - `getTaskToday()` - получение задач на сегодня
  - `getTaskTomorrow()` - получение задач на завтра

#### 2. DailyTasksScreen (`lib/screens/daily_tasks_screen.dart`)
- **Назначение**: экран редактирования ежедневных задач
- **Особенности**:
  - Универсальный компонент для обеих страниц
  - Автосохранение с таймером (2 секунды)
  - Индикаторы загрузки и сохранения
  - Адаптивный дизайн

### Автосохранение
```dart
// Умная логика автосохранения
void _onFocusChanged() {
  // Сохраняем при потере фокуса (окончание печати)
  if (!_focusNode.hasFocus && _controller.text != _lastSavedText) {
    _saveText();
  }
}

void _onTextChanged() {
  _saveTimer?.cancel(); // Отменяем предыдущий таймер
  _saveTimer = Timer(const Duration(seconds: 3), () {
    if (_controller.text != _lastSavedText) {
      _saveText(); // Защитное сохранение через 3 секунды
    }
  });
}

@override
void dispose() {
  // Сохраняем при закрытии страницы, если есть изменения
  if (_controller.text != _lastSavedText) {
    _saveTextSync();
  }
  // ... остальная очистка ресурсов
}
```

### Оптимизации
- **Избежание дублирования**: сохранение только при реальных изменениях текста
- **Отслеживание состояния**: переменная `_lastSavedText` для сравнения
- **Множественные триггеры**: потеря фокуса, таймер, закрытие страницы
- **Синхронное сохранение**: для случаев быстрого закрытия приложения
