# 🖥️ Руководство по адаптивному дизайну

## Обзор
Приложение Task Planner теперь поддерживает полноценный адаптивный дизайн с отдельными компоновками для мобильных устройств, планшетов и десктопов.

## 📱 Breakpoints (точки перехода)

- **Мобильные**: < 768px
- **Планшеты**: 768px - 1024px  
- **Десктоп**: > 1025px

## 🖥️ Десктопная компоновка

### Структура
```
┌─────────────────────────────────────────────────┐
│ AppBar (Task Planner + кнопки навигации)        │
├───────────────────┬─────────────────────────────┤
│ Левая панель      │ Основная область задач      │
│ (300px)          │ (остальное пространство)    │
│                   │                             │
│ ┌───────────────┐ │ ┌─────────────────────────┐ │
│ │ Переключатель │ │ │ Список задач            │ │
│ │ Календарь/    │ │ │                         │ │
│ │ Ближайшие     │ │ │ ┌─────────────────────┐ │ │
│ └───────────────┘ │ │ │ Карточка задачи     │ │ │
│                   │ │ │ (полная ширина)      │ │ │
│ ┌───────────────┐ │ │ └─────────────────────┘ │ │
│ │ Календарь или │ │ │                         │ │
│ │ Ближайшие     │ │ │ ┌─────────────────────┐ │ │
│ │ задачи        │ │ │ │ Карточка задачи     │ │ │
│ └───────────────┘ │ │ └─────────────────────┘ │ │
│                   │ │                         │ │
│ ┌───────────────┐ │ │                         │ │
│ │ Фильтры тегов │ │ │                         │ │
│ └───────────────┘ │ │                         │ │
└───────────────────┴─────────────────────────────┘
```

### Левая панель (sidebar)
- **Ширина**: 300px фиксированная
- **Переключатель режимов**: Календарь ↔ Ближайшие задачи
- **Календарь**: Полноразмерный календарь для выбора дат
- **Ближайшие задачи**: Компактный список из 5 ближайших задач
- **Фильтры тегов**: Компактные чипы для фильтрации

### Основная область
- **Ширина**: Оставшееся пространство (максимум 1400px)
- **Содержимое**: Полный список задач с выравниванием по ширине
- **Карточки**: Единообразная ширина на всю область

## ✨ Ключевые улучшения

### 1. **Выравнивание по ширине**
- ✅ Все карточки имеют одинаковую ширину
- ✅ Календарь и фильтры в sidebar выровнены
- ✅ Использование `SizedBox(width: double.infinity)`
- ✅ Унифицированные отступы через `Responsive` класс

### 2. **Компактный sidebar**
- ✅ Оптимизированные размеры элементов
- ✅ Компактные карточки для ближайших задач
- ✅ Уменьшенные шрифты для экономии места
- ✅ Единообразные отступы `EdgeInsets.zero`

### 3. **Адаптивные отступы**
- **Мобильные**: 8px
- **Планшеты**: 12-16px  
- **Десктоп**: 16-24px

### 4. **Responsive компоненты**
- `Responsive.isDesktop()` - проверка устройства
- `Responsive.getSidebarWidth()` - ширина sidebar
- `Responsive.getCardMargin()` - отступы карточек
- `Responsive.getAppPadding()` - отступы приложения

## 🔧 Техническая реализация

### Основные файлы
- `lib/utils/responsive.dart` - система responsive дизайна
- `lib/screens/home_screen.dart` - главная компоновка
- `_buildDesktopLayout()` - десктопная версия
- `_buildMobileLayout()` - мобильная версия

### Адаптивная логика
```dart
if (Responsive.isDesktop(context)) {
  return _buildDesktopLayout(taskProvider);
} else {
  return _buildMobileLayout(taskProvider);
}
```
